# ShopEasy Pro - Single Page Shopping Platform

## Live Demo
🌐 **Open Shopping App:** https://open-shoping.netlify.app/

## Features
- ✅ **Add/Edit/Delete Products** with images
- ✅ **Shopping Cart** with quantity management
- ✅ **Category Management** with color coding
- ✅ **Sales Reports** and analytics
- ✅ **QR Code Payment** integration
- ✅ **Store Configuration** (name, colors, currency)
- ✅ **Local Storage** - all data saved in browser
- ✅ **Mobile Responsive** design

## How to Use
1. **Visit** the link above
2. **Add Products**: Click + button or "Add Product"
3. **Configure Store**: Click gear icon for settings
4. **Manage Categories**: Navigate to Categories page
5. **Add to Cart**: Click "Add to Cart" on products
6. **Checkout**: Process orders from cart
7. **View Reports**: See sales statistics
