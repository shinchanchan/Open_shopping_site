

# 🛒 ShopEasy Pro – Purchase & Billing Management System

**ShopEasy Pro** is a **single-page shopping, purchase, and billing platform** designed for **small and medium businesses**.
It allows store owners to manage **products, categories, billing, sales, and reports** — all in one place, with **no server, no login, and no recurring cost**.

🌐 **Live Demo:**
👉 [https://open-shoping.netlify.app/](https://open-shoping.netlify.app/)

---

## 🚀 Key Highlights

* 💻 **Single Page Application**
* 🧾 **Purchase & Billing Management**
* 🏪 **Store Configuration**
* 📱 **Mobile & Desktop Friendly**
* 🔐 **100% Client-Side (No Server Needed)**

## ✨ Features

### 🛍️ Product & Purchase Management

* ➕ Add / ✏️ Edit / 🗑️ Delete products
* 🖼️ Product image support
* 📦 Quantity and price handling
* 🧮 Automatic total calculations

### 🛒 Billing & Cart

* Smart shopping cart
* Quantity increase / decrease
* Automatic bill amount calculation
* Simple checkout flow

### 🗂️ Category Management

* Create and manage categories
* Color-coded categories for clarity
* Easy product categorization

### 📊 Sales & Reports

* Daily / overall sales tracking
* Simple analytics for business insight
* Helps understand purchase trends

### 💳 Payment Support

* QR Code based payment display
* Supports UPI / digital payments

### ⚙️ Store Configuration

* Store name
* Theme color
* Currency selection
* Business-level customization

### 💾 Data Storage

* All data saved in **browser localStorage**
* No internet required after first load
* No login or registration

## 🧭 How to Use

1. **Open the App**
   👉 [https://open-shoping.netlify.app/](https://open-shoping.netlify.app/)

2. **Add Products**

   * Click **“+”** or **Add Product**
   * Enter name, price, category, image

3. **Configure Store**

   * Click the **⚙️ Settings icon**
   * Set store name, color & currency

4. **Manage Categories**

   * Go to **Categories**
   * Add or update category colors

5. **Create Bill / Purchase**

   * Add products to cart
   * Adjust quantity
   * Proceed to checkout

6. **View Reports**

   * Check sales statistics & totals
